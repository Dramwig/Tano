# Bundled callout icons

The five unmodified duotone SVGs in `phosphor/` come from
[Phosphor Icons](https://github.com/phosphor-icons/core), commit
`2b75f3ad12b420c9504ef05df8d2564a28f8500e`. The MIT license is retained in
[phosphor/LICENSE](phosphor/LICENSE).

| Callout | Upstream asset |
| --- | --- |
| NOTE | `assets/duotone/info-duotone.svg` |
| TIP | `assets/duotone/lightbulb-duotone.svg` |
| IMPORTANT | `assets/duotone/sparkle-duotone.svg` |
| WARNING | `assets/duotone/warning-duotone.svg` |
| CAUTION | `assets/duotone/shield-warning-duotone.svg` |

These assets are bundled locally so callout icons also work offline. The SVGs
are rendered inline to inherit each callout's theme-aware color.
