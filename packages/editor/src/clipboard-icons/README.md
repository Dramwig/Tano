# Clipboard platform icons

`wechat.vue` and `zhihu.vue` are locally drawn outline adaptations of the WeChat
and Zhihu marks. They retain the double speech bubbles and the stylized 知 glyph,
respectively, while matching the menu's 24-unit SVG grid, 1.6-unit strokes,
rounded line caps and joins, and `currentColor` treatment. No solid badge or
brand color is used. Icons are decorative because the buttons have visible labels.

These local SVG drawings use the repository's MIT license. Brand marks remain
the property of their respective owners.
