# Import provider brand icons

Ten unmodified SVGs from [Simple Icons 15.0.0](https://github.com/simple-icons/simple-icons/tree/15.0.0/icons), distributed under [CC0-1.0](LICENSE.md). These are bundled locally; no network requests are needed to display them.

| --- | --- | --- |
| notion.svg | Notion | https://www.notion.so |
| obsidian.svg | Obsidian | https://obsidian.md |
| confluence.svg | Confluence | https://www.atlassian.com/company/news/press-kit |
| evernote.svg | Evernote | https://evernote.com/about-us |
| trello.svg | Trello | https://atlassian.design/resources/logo-library |
| roamresearch.svg | Roam Research | https://roamresearch.com/#/app/help/page/Vu1MmjinS |

| quip.svg | Quip | https://quip.com |
| googledocs.svg | Google Docs | https://docs.google.com |

Sources and brand colors are recorded in the upstream [metadata](https://github.com/simple-icons/simple-icons/blob/15.0.0/data/simple-icons.json). Tano displays the original paths with CSS colors. The SVG files themselves are unchanged.

`workflowy.svg` and `monday.svg` are original Tano list and board pictograms, licensed under the repository's MIT license. They are used to identify those import options and are not official brand logos.
