## 格式清单

| 类别 | 可以检查的格式 |
| --- | --- |
| 基础块 | H1–H6、段落、引用、无序/有序/待办列表、代码围栏、GFM 表格、图片、分隔线、Mermaid 和独立公式 |
| 行内格式 | 粗体、斜体、代码、普通/引用式/自动链接、删除线、公式、脚注、转义和硬换行 |
| 文字扩展 | `<u>`、`<sup>`、`<sub>`、`<mark>` 和受限的 `<span style="color: #RGB/#RRGGBB">` |
| 文档链接 | `[[文档]]`、`[[文件夹/文档\|别名]]` 和 `[[文档#标题]]` |
| 增强块 | NOTE/TIP/IMPORTANT/WARNING/CAUTION、Toggle、File、Embed、Tabs 和 Columns；Panel 属于标签页或分栏内部结构 |
| 公式 | 行内 `$...$` / `\(...\)`，块级 `$$...$$` / `\[...\]` |
| 属性 | YAML 字符串、数字、布尔、空值、列表、多行字符串、嵌套对象和注释 |
| 对象 | 可编辑的 Person、Task、Project 和 Event，以及由应用分配身份的 Document/Asset 引用 |

本清单不表示兼容所有 CommonMark 方言或任意 HTML/CSS。普通 HTML 可在本地预览并在源码模式保留；它与受限文字样式标签的实时协作支持不同。

## 建议操作顺序

1. 逐篇打开，对照源码模式与富文本视图。
2. 编辑段落、切换模式、保存并重新打开，检查 Markdown 语义。
3. 尝试块手柄、斜杠菜单、工具栏、撤销和重做。
4. 在 `05-链接图片与附件.md` 检查链接与标题跳转、图片预览和附件下载。
5. 在 `06-对象引用.md` 检查对象解析及改名后的引用。
6. 在桌面版用外部编辑器改一行，检查文件监听；并发修改同一行，检查冲突副本。

## 能力开关

在工作区的文档能力设置中，逐项关闭/开启 `objectReferences`、`math`、`mermaid`、`wikiLink`、`callout`、`footnotes`、`embed`、`html` 和 `enhanced`，检查源码降级与恢复。文档能力、渲染偏好和对象创建入口是不同设置。

在源码模式修改 YAML，检查注释、顺序和多行写法。`created`、`updated`、`date`、`created_at` 和 `updated_at` 可用于日期字段测试；任意属性键不会自动获得专用业务 schema。

预置对象记录位于外层工作区根目录的 `.tano/objects/`。Document/Asset 短 ID 由应用分配，请在界面选择目标创建引用，不要猜测 ID。浏览器示例与本地工作区相互独立，没有网络同步或真实 Agent 连接。
