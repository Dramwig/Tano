# 多块编辑与布局

[English](../en-US/10-block-editing-and-layout.md) · [导航](00-从这里开始.md)

## 选中几块，只修改几块

第一段：把「待整理」改为「已整理」。**保留加粗**和这个[目标链接](子目录/目标文档.markdown)。

中间段：这是不参与修改的对照段。选择不连续块时跳过这一段。

第三段：把「待整理」改为「已整理」，保留公式 $a+b=c$。

- [ ] 使用块手柄或框选选中第一段和第三段，在块菜单中进入 Markdown 源码编辑。
- [ ] 分别修改选中的内容，退出源码编辑，检查中间段没有改变。
- [ ] 再选中连续的几块，检查它们可以一起编辑源码。
- [ ] 撤销和重做，检查文字、块顺序及未选中的内容。

## 拖动与分栏

把这段拖到下面提示块的左侧或右侧，出现竖直指示线后放下，可创建分栏。

> [!CUSTOM:💡]
> 点图标可以更换表情或内置图标。拖动块到上方或下方则调整纵向顺序。

- [ ] 拖动分栏边界调整比例；按 Esc 取消本次拖动，双击边界恢复相邻等宽。
- [ ] 调窄窗口，检查分栏堆叠显示；恢复宽度后检查原比例。

## 表格自动宽度

| 检查项 | 操作 | 预期 |
| --- | --- | --- |
| 固定宽度 | 拖动列边界 | 保留自定义列宽 |
| 自动宽度 | 在表格菜单中恢复自动宽度 | 随容器宽度调整 |
| 单元格颜色 | 设置文字或背景颜色 | 恢复自动宽度不清除颜色 |

表格文字保存在 Markdown，列宽与单元格颜色保存在 `.tano/` 的文档布局中。只复制 Markdown 不会携带这些布局设置。建议编辑可以修改表格文字，但不保存列宽与颜色。

## 阅读设置

- [ ] 在页面显示选项中尝试宽度、字体和源码显示，再打开文档查找与大纲。
- [ ] 拖动格式工具栏到支持的停靠位置，并在设置中检查快捷键。
- [ ] 锁定页面进入阅读状态，再解锁继续写作；页面锁定不会改变磁盘文件权限。
