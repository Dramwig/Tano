# 数据表与视图

[English](../en-US/13-data-tables-and-views.md) · [导航](00-从这里开始.md)

## 选择合适的数据形式

| 形式 | 适合用途 | 内容位置 |
| --- | --- | --- |
| Markdown 表格 | 文档内的小型比较 | 当前 `.md` 正文 |
| 数据表 | 持续维护记录、字段与公式 | 普通 `名称.table.json` 文件 |
| 文件数据库 | 筛选工作区文件和属性 | 原文件；视图位于 `.tano/` |
| 对象数据库 | 人物、任务、项目、事件、实验 | `.tano/objects/` 中的对象 |

## 创建一张验收表

在文件树菜单中新建数据表，命名为「功能验收」。添加名称（文本）、状态（单选）、工作量（数字）字段，输入以下练习数据：

| 名称 | 状态 | 工作量 |
| --- | --- | ---: |
| 编辑器 | 待检查 | 2 |
| 文件导航 | 检查中 | 1 |
| 引用 | 已完成 | 1 |

- [ ] 从上表复制记录，检查多行多列粘贴、Enter 下一行与 Shift+Enter 换行。
- [ ] 增加公式 `IF([状态] = "已完成", [工作量], 0)`，检查计算列和底部汇总。
- [ ] 保存表格、看板和卡片视图；按状态分组、筛选未完成记录，再改回查看全部。
- [ ] 导出当前视图为 CSV。CSV 不包含原公式定义、视图和附件文件。
- [ ] 重命名并移动数据表，重新打开，确认记录仍在；不要把文件直接改成 `.xlsx`。

## 对象与文件视图

使用[对象引用示例](06-对象引用.md)中的人物、任务、项目和事件练习对象视图。改名后回到引用页检查当前名称，切换表格、看板和画廊时检查同一记录没有被复制。

建立文件视图，筛选本语言目录中的 Markdown，再检查[属性样本](02-YAML-属性字段.md)的 YAML 字段。视图展示原内容，不会把 Markdown 正文迁移到数据库。

## 外部编辑与恢复

桌面端可在数据表副本上检查外部单元格编辑：互不影响的修改可以合并，同一单元格冲突须保留两边内容。数据表提示冲突时使用重试、另存副本或保留恢复文件后重新载入。浏览器演示只保存到当前浏览器，不代表多人实时编辑数据表。
