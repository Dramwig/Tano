# 对象引用

[English](../en-US/06-object-references.md) · [导航](00-从这里开始.md)

预置记录位于外层工作区根目录的 `.tano/objects/`。引用使用六位小写十六进制 ID，身份与文件路径无关。

- Person：[@测试人物](object://person/e82f91)
- 历史 Task：[@检查渲染](object://task/f82f91)
- 历史 Project：[@Markdown 验收](object://project/182f91)
- Event：[@验收会议](object://event/282f91)

下面的独占段落通过 `tano:object-card` 标题成为对象卡片：

[验收会议](object://event/282f91 "tano:object-card")

在对象面板修改 Person 或 Event 名称，检查引用是否仍按 ID 解析。Task 和 Project 是历史兼容示例：记录仍可读取，但这些已停用类型不再支持创建或修改。当前待办使用可勾选的 Event 记录。

[[子目录/目标文档]] 按路径查找文档；绑定后的 Document/Asset 引用使用应用分配的短 ID。在 `@` / `[[` 选择器中创建引用，重命名目标，再检查身份跟踪。

两种语言各有对应的对象记录和名称。这些 JSON 属性与 YAML 顶部属性不同。浏览器 demo 使用内置记录，不会修改本地工作区。
