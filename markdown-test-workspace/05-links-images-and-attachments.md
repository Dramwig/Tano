# Links, images, and attachments

## Document links

* Standard relative link: [Target document](nested-folder/target-document.markdown).
* Wiki link: [[nested-folder/target-document]].
* Wiki alias: [[nested-folder/target-document|Target alias]].
* Wiki heading anchor: [[nested-folder/target-document#Target section|Section alias]].
* External HTTPS link: [Example](https://example.com "Title attribute").

Click a Wiki link to navigate. In rich text, use Ctrl/Command-click for a standard link. You can also move or rename a file to observe how path-based links behave.
