- [ ] 标题、列表、表格和行内样式 / Headings, lists, tables, and inline styles

## 存储与能力 / Storage and capabilities

**浏览器演示**：这些是内置示例副本，修改仅保存在当前浏览器；不会读取本地文件夹、同步两个工作区、连接真实 Agent 或提供多人实时协作。可预览示例图片并下载附件；导入新附件请使用桌面版。

**Browser demo**: These are bundled sample copies. Edits stay in this browser. The demo does not read local folders, sync the two workspaces, connect a real agent, or provide live collaboration. Sample images and attachment downloads work; use the desktop app to import new attachments.

**桌面本地工作区**：在桌面版打开本文件夹，Markdown 和附件就是普通文件。文件监听、外部修改合并与冲突副本需要在桌面版验收。

**Local desktop workspace**: Open this folder in the desktop app to work with ordinary Markdown files and attachments. Test filesystem watching, external-edit merging, and conflict copies there.

中文与英文覆盖相同的测试项目，验收样本及其附件分别放在 `zh-CN/` 和 `en-US/` 中。根目录的 `new-document.md` 是独立试写文件。

Both languages cover the same checks. QA samples and their attachments live in `zh-CN/` and `en-US/`. The root-level `new-document.md` is a separate scratch document.
