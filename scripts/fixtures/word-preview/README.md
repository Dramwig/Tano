# Word preview fixtures

`fixture.doc` is Apache POI's `test-data/document/simple.doc`, distributed under
Apache-2.0 (see [LICENSE.txt](LICENSE.txt)). Copyright The Apache Software Foundation.
Source: https://github.com/apache/poi/blob/trunk/test-data/document/simple.doc
SHA-256: `4876e828e62d490fa188c7c4e47013e2e0dfdf02f5903dfd374bc0d2b2049ca1`.
It is also byte-identical to the user's existing legacy Word preview test file.

`fixture.docx` is a Tano-authored OOXML fixture (MIT), generated by
[create-word-preview-fixture.mjs](../../create-word-preview-fixture.mjs).
It contains three pages: two landscape pages followed by a portrait section,
original page margins, green italic 24 pt text, a merged yellow table cell,
an embedded test image, headers, footers and an explicit page break.
`image.png` is a generated solid-colour 120 × 60 test image (MIT).
No Office installation is required to regenerate the DOCX or run the tests.
