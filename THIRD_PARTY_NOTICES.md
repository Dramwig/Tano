Attribution, the full graphics license, source version, coordinate metadata, and asset hashes are retained in [packages/workbench/src/assets/emoji/twemoji/](packages/workbench/src/assets/emoji/twemoji/README.md) and the generated client distribution notices. Tano selects base emoji and combines Simplified Chinese and English metadata into nine categories while retaining curated names. Attribution, license, and input hashes are retained in [packages/workbench/src/assets/emoji/emojibase/](packages/workbench/src/assets/emoji/emojibase/README.md) and the generated client distribution notices.

`npm run notices:generate` collects LICENSE, COPYING, and NOTICE files from the current npm and Cargo dependencies. It writes `apps/client/public/THIRD_PARTY_NOTICES.txt` and the MCP distribution notice file. Desktop and MCP distributions include the generated notices. Regenerate them after updating dependencies; Tano's MIT license does not replace third-party obligations.
