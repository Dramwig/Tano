# 備份與復原

[English](../backup-recovery.md) | [简体中文](../zh/backup-recovery.md) | 繁體中文 | [日本語](../ja/backup-recovery.md) | [Español](../es/backup-recovery.md) | [Deutsch](../de/backup-recovery.md) | [文件目錄](README.md)

請一併備份 Markdown 檔案、附件及完整的 `.tano/` 目錄。工作區 UUID、檔案身分、物件、關係與規則都是需要保留的可攜原始資料。

Tano 不會自動備份工作區，也不提供工作區封存檔的匯入、匯出或還原。如果在 Tano 之外刪除了工作區資料夾，開啟時會失敗。請使用自己的備份工具、版本控制或作業系統的資源回收筒來還原資料。

若工作區資料夾仍在，但整個 `.tano/` 目錄已遭刪除，重新開啟時會以新的 UUID 和檔案 ID 初始化工作區。系統會提示原始中繼資料已遭刪除、舊的物件資料已遺失，而且專案已重新初始化。原有的 Markdown 與附件仍在。隨 `.tano/` 刪除的物件、關係及規則需從備份還原，重新初始化也不會沿用舊工作區的索引、草稿或工作階段。部分身分中繼資料遺失、損毀或不相符時，工作區仍無法開啟。已開啟的工作階段會停止寫入，直到重新開啟並初始化工作區。

草稿日誌保存在應用程式資料中，供應用程式重新啟動後取回未儲存的變更。工作區仍須另行備份。若檔案受到外部修改，仍會比較基準雜湊、執行三方合併，並在發生衝突時保留兩個版本。
