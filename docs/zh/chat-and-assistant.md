# 聊天与助手的产品边界

账号体系下的私聊、群聊、联系人和聊天机器人属于 `Tano-cloud`。聊天专用界面、数据模型、状态、演示、通讯服务与部署均由云端产品维护。公开 Tano 的本地版和浏览器演示不提供聊天入口。

公共工作台通过[Cloud Extension API](../cloud-extension.md)提供通用扩展视图：导航、单一标签页、侧栏、弹窗宿主与标签恢复。扩展声明稳定视图 ID，只有当前产品注册的视图才会恢复；缺少扩展时跳过该标签，保留文档和草稿。公共核心不导入聊天模块，也不持有账号或消息状态。范围约定见[仓库许可](license.md)。

真实聊天属于账号层，不以当前工作区路径作为身份，不进入工作区 Markdown 恢复日志。缓存放在应用数据；只有用户明确保存为文档的聊天内容才创建普通 Markdown 文件。引用工作区内容使用工作区 UUID 与稳定对象或文件 ID。

本地 Agent / MCP 工作流继续属于公开核心。未来助手的模型对话、任务执行、权限确认、文件差异与结果审阅应与普通聊天分离。聊天机器人不因加入会话而获得本地文件或命令执行权限。

助手执行器须独立于聊天和编辑器，复用[Agent 工作流](agent-workflow.md)的条件写入原则：先读后写并比较基准哈希，合并独立编辑，冲突时保留双方版本，不能越过所选工作区的符号链接边界。
