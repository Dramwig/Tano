# 备份与恢复

[English](../backup-recovery.md) | 中文 | [日本語](../ja/backup-recovery.md) | [Deutsch](../de/backup-recovery.md) | [文档目录](README.md)

请将 Markdown 文件、附件和整个 `.tano/` 目录一起备份。工作区 UUID、文件身份、对象、关系和规则均为可移植的源数据，不是可随意删除的缓存。

原生核心在应用数据中保存元数据快照。已知工作区丢失身份后，普通打开与写入会停止。应通过恢复流程预览并确认恢复，而不是分配新 UUID。完整导出包含文档正文和应用数据；导入会验证字节摘要，且不会覆盖已有目标。

草稿 journal 也位于应用数据中。外部文件变化仍经基线 hash 比较、三方合并和冲突保留处理。恢复失败会保留数据与记录。本地快照有助于恢复，但仍应在其他设备或介质上保存独立备份。
