# 备份与恢复

[English](../backup-recovery.md) | 中文 | [日本語](../ja/backup-recovery.md) | [Deutsch](../de/backup-recovery.md) | [文档目录](README.md)

请将 Markdown 文件、附件和整个 `.tano/` 目录一起备份。工作区 UUID、文件身份、对象、关系和规则均为可移植的源数据，不是可随意删除的缓存。

同页不生成工作区自动备份，也不提供工作区归档导入、导出或恢复。用户在同页之外删除工作区文件夹后，打开该路径会报错；同页不会重建目录或恢复其中的内容。需要找回文件时，请使用自行配置的备份工具、版本控制或操作系统回收站。

工作区文件夹仍在、但整个 `.tano/` 被删除时，重新打开会把该文件夹作为新工作区初始化：生成新的工作区 UUID 和文件 ID，并提示原 `.tano/` 已删除、旧对象数据丢失、项目已重新初始化。已有 Markdown 和附件保持原样，随 `.tano/` 删除的对象、关系和规则不会恢复，也不沿用旧工作区的索引、草稿或会话。只有部分身份文件缺失、损坏或身份不匹配时仍停止打开；正在打开的会话也会停止写入，直到重新打开完成初始化。

草稿 journal 位于应用数据中，用于保留应用重启前未保存的编辑，不是工作区备份。外部文件变化仍经基线 hash 比较、三方合并和冲突保留处理。
