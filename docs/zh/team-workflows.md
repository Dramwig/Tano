# 团队持续工作

## AI 跟进已有任务

允许检索当前工作区和读取对象后，助手可按文档、目录、负责人和状态查询任务，返回原任务链接、日期及关联文档依据。整理会议行动项时先查询已有任务，区分新增、更新和可能重复；重复候选需要额外确认才能新增。周报按已完成、待处理、逾期分类，未记录的阻塞原因标为「未知」。

改期预览显示原日期和新日期；确认后修改原任务，保留稳定身份、正文引用和外部同步身份。负责人调整与关系维护也需逐项确认。并发修改使预览失效时重新审阅；重叠修改不会静默覆盖。

## 轻量交付审阅

Cloud 任务执行者选择已保存的结果文档和具备编辑权限的审阅成员，提交后进入审阅人收件箱。审阅者可以要求修改并填写意见，或通过并完成原任务。结果文档或任务要求变化后不能通过旧提交，执行者须重新提交。

审阅记录保存交付文档稳定 ID、内容 hash、任务要求 hash、执行者与审阅人物身份，位于原任务对象的 `deliveryReview` 属性。正文仍是普通 Markdown。归档人物不能提交或审阅，账号绑定和权限检查由 Cloud 服务端执行。AI 可根据要求与结果文档检查覆盖情况并附依据，最终决定由指定审阅人确认。

官方桌面打开在线工作区时复用桌面模型连接，会话缓存在设备应用数据中并按服务器、账号和工作区隔离。网页工作区没有托管模型接口。真实模型质量须使用已配置连接单独评估；脚本模型执行器测试只能证明查询、提案和确认链路。

## 文档模板

从工作区菜单或文档更多菜单打开「文档模板」。提供会议纪要、周报和交接模板；填写字段、查看正文预览后创建普通 Markdown。自定义或新建模板可复用当前文档。

自定义模板正文保存在 `.tano/templates/<六位短 ID>.md`，名称位于同一 Markdown 的 `tanoTemplate` YAML 属性中，随工作区同步，不进入普通文档检索、引用目标和项目目录。占位符使用 `{{title}}`、`{{date}}`、`{{owner}}`、`{{project}}`，也支持英文字母开头的自定义字段。模板名称属性不复制到新文档，用户原有 YAML 属性保留，字段值通过 YAML 解析器替换和转义。保存时比较基线 hash，合并独立编辑；重叠编辑保留草稿并提示另存或重新读取。

## 重复任务

工作区任务详情支持每天、每周、每月及间隔和结束日期。使用全天计划日期或截止日期；月末规则使用日历库，某月没有对应日期时跳到下个有效月份。完成当前任务并保存后，选择「预览下一次」，核对日期、负责人和关联，确认创建一个新实例。

规则与实例来源保存在 `.tano/objects/` 中。系列与发生日期生成稳定实例身份，重复确认返回同一任务；同一周期不生成两份。新实例复制文档引用、关联和负责人，清除完成状态、交付审阅及外部同步身份。来源任务或关联变化后须重新预览。实例自身不能修改系列规则，调整规则在来源任务上进行。

这是明确确认的下一次创建流程，没有后台定时器或自动补建历史任务。对象和关系分别条件保存，无法提供跨文件事务；关系保存失败时任务保留，重新确认可补齐关联，不覆盖已被其他人修改的实例。项目继续由目录和首页 Markdown 承载。
