# 文件夹首页

默认情况下，文件夹直属的 `README.md` 是该文件夹的首页。进入**工作区设置 → 文件夹首页**，可以改用 `_index.md`、`index.md`，或关闭识别。只识别所选的一个文件名，大小写精确匹配；其他 Markdown 文件仍正常显示。

- 点击文件夹名称打开首页；点击图标展开或收起。鼠标悬停图标时显示箭头，触屏设备始终显示箭头。
- 没有首页的文件夹保持普通行为，点击行即可展开或收起。
- 首页在文件树中由文件夹代表，显示文件夹名及首页的自定义图标。打开首页时选中对应文件夹。
- 聚焦文件夹后，Enter 打开首页，左右方向键展开或收起。
- 文件夹右键菜单中的“打开首页”可直接打开文档；“显示首页文件”会展开目录并显示、选中真实 Markdown 文件，方便单独重命名等操作。显示后该菜单项变为“隐藏首页文件”，点击后恢复由文件夹代表首页，已打开的文档不受影响。该显示状态不跨工作区或设置切换保存。
- 面包屑中的文件夹名称打开首页，旁边的下拉箭头保留目录浏览功能。当前首页不会额外显示一层 `README`。

文件夹的重命名、移动和删除仍作用于整个目录。首页始终是普通 Markdown 文件，保留原有文件 ID、路径、搜索和引用能力；工作区根目录的 `README.md` 保持可见。外部新增、删除或重命名首页后，文件列表刷新会重新识别。

首页识别本身只调整展示和导航。设置通过现有的 `.tano/settings.tano.json` 保存，沿用外部修改冲突检测，不写入 `.tano/config.json`。

## 给现有文档添加子文档

在 Markdown 文档上右键选择“新建子文档”。例如，`设计.md` 会变为 `设计/README.md`，同时创建 `设计/新建文档.md` 并进入命名状态。首页文件名遵循当前工作区设置；已是首页的文档会直接在所属目录新增子文档，不再嵌套一层。已有同名目录时停止转换，不会合并目录或覆盖内容。

## 转回普通文档

文件夹右键菜单提供“转为普通文档”。仅当目录中只剩被识别的首页、且外面的同名 `.md` 文件不存在时可用。例如，`设计/README.md` 会移为 `设计.md`，随后移除空目录。目录中的任何其他文件、附件、子目录、隐藏文件或并发新增的内容都会阻止移除。此操作只由用户主动执行，不会自动触发。

## 内容、链接与失败恢复

两个方向均保留首页的文件 ID，在转换前保存打开的草稿，并更新打开的文档状态。会更新 Markdown 链接与图片、引用式链接定义、Wiki 链接、附件相对路径和相对封面路径；链接标题、别名、锚点、代码示例与基于 ID 的对象引用保持不变。原来无法解析的 Wiki 链接不会猜测目标。

若原始 HTML 中含有需要随转换调整的资源路径，会在移动前要求先改为 Markdown 链接。其他自定义元数据中的字符串不是自动识别的文件引用。需要修改的文档为只读时，转换也会在移动前停止。

写入使用基准哈希校验，独立外部修改通过三方合并保留。操作失败时尝试恢复原有结构和链接；若外部修改阻止安全恢复，保留现有文件，并将转换前后内容与路径记录在 `.tano/conflicts/folder-conversion-*.json`，错误提示会给出记录路径供手动恢复。跨文件转换并非文件系统级原子事务，不应在过程中强制结束应用。

浏览器演示和原生文件系统适配器支持此操作。其他存储适配器需要提供按身份与哈希校验的 `changeFile` 和只允许删除空目录的 `removeEmptyFolder`，否则入口禁用。
