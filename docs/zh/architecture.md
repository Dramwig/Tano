# 架构

[English](../architecture.md) | 中文 | [日本語](../ja/architecture.md) | [Deutsch](../de/architecture.md) | [文档目录](README.md)

Vue 工作台通过文档 store 使用 `WorkspaceAdapter`。桌面适配器调用由 `tano-native` 实现的 Tauri IPC 命令；浏览器演示使用独立的浏览器存储适配器。`configureWorkbench(pinia, runtime)` 将一个运行时绑定到每个工作台实例。

```text
Vue 工作台 -> 文档 store -> WorkspaceAdapter -> Tauri IPC -> tano-native
```

Markdown 文件是内容的事实源。编辑器与无界面 codec 使用相同的 Markdown schema。编辑器通过 `EditorExtension` 接收宿主功能，使编辑与存储、传输保持分离。

每次保存都对比文件与基线 hash。独立的外部修改可合并；重叠修改则保留双方版本供检查。对不与 Tano 协调的外部进程，最后一次 hash 检查与原子替换之间仍有很短的竞争窗口。

工作区身份与文件路径无关。工作区 UUID、文件短 ID 和 ID 占号随 `.tano/identities.json` 携带。对象、关系和规则也保存在 `.tano/`；SQLite 索引、草稿及恢复状态位于工作区外的应用数据中。Tano 不会跟随指向选定工作区外部的符号链接。

## 计划事件

计划侧栏与日历共用选中日期，展示当天的任务与日程，以及未安排的任务。新任务和日历条目统一使用 `.tano/objects/` 中的 `event` 对象，其可选属性为：

- `checkable`：是否需要完成；`completed` 记录完成状态。
- `date`：仅安排日期，使用本地 `YYYY-MM-DD` 格式。无需勾选完成，可用于纪念日或提醒日；日历时间网格顶部单独展示，月、年及日程视图也可查看。
- `start`、`end`：成对的带时区时间戳。具有时间段的事件显示在日历中，也可以同时需要勾选完成。

`date` 与 `start`/`end` 二选一。需要完成、但没有日期或时间段的事件进入「未安排」。勾选完成或安排日期都通过原有基线 hash 合并机制更新同一个对象。截止日期与计划执行日期分别表达。Markdown 待办仍保留在原文档中，不复制为事件记录。

新建和详情共用时间安排控件，提供「未安排 / 计划日期 / 时间段」三个选项。「计划日期」和「时间段」均通过单个文字按钮切换全天事件与精确时间，保留已选日期和本次编辑中填写的时刻。具体时刻没有默认时长，保存为 `start === end`。全天时间段填写开始、结束日期，包含结束当天；保存为 `allDay: true` 和从开始日零点到结束日次日零点的 `start`/`end`，与日历的半开区间约定一致。完成状态与日期粒度独立。

已有 `task` 文件保留原 ID 和引用地址，仍可读取和编辑，并兼容展示在计划侧栏中。工作台新建的任务统一保存为 `event`，创建表单不再提供单独的任务对象类型。

### 个人与工作区归属

新建事件或任务时可选择「个人」或「工作区」。已有事项保持工作区归属，不进行自动迁移。计划侧栏和日历共享「工作区 / 个人 / 全部」筛选；「全部」明确表示个人事项与当前工作区事项。来源标签与复合视图键区分不同空间中可能重复的短 ID，完成、改期和详情编辑都写回原来源。

工作区事项继续保存在工作区的 `.tano/objects/`。桌面个人事项保存在应用数据目录的独立 `personal/.tano/objects/` 文件中，其身份文件也位于 `personal/.tano/`；可重建索引位于应用数据目录的 `personal-index.sqlite`。个人文件属于用户内容，不是可丢弃的缓存。个人操作通过独立 IPC 和存储适配器进行，不切换当前工作区，不加入工作区引用、搜索、插件目录或工作区导出。用户在欢迎页未打开工作区时也能进入个人计划；工作区只读或关闭对象功能不影响个人事项。

浏览器演示的个人事项使用独立的 `tano.personal-plans.v1` 存储键，每次写入使用 Web Locks 与最新基线 hash；缺少锁支持时拒绝写入。桌面使用进程协调锁与现有文件原子写入机制。两种适配器复用对象合并逻辑，冲突时保留磁盘版本和编辑草稿，不重置损坏数据。

「个人」指本设备或本浏览器的独立空间，不是 Tano 账号私有云。桌面端可配置独立的日历和 Todo 连接，通过第三方服务同步选定事项；账号配置与基线位于应用数据目录，密码和令牌位于系统凭据库。浏览器与移动端当前仅提供 iCalendar 文件导入。接入方式、冲突行为与验证限制见[日历与 Todo 同步](planning-sync.md)。归属与负责人是不同概念；当前没有将人物记录绑定到登录身份，也不将工作区全部事项称作「分配给我」。跨工作区责任筛选和归属迁移尚未提供。
