# Tano Local 隐私说明

更新日期：2026 年 10 月 30 日。[English](../local-privacy.md) · [Code signing policy](code-signing-policy.md)

## 范围与本地数据

本说明适用于 Zixi Wang（Dramwig）维护的公开 MIT 桌面产品 [Tano Local](https://github.com/Dramwig/Tano)，描述当前公开源码。具体版本可能尚未包含所有功能，请以随包源码标签和声明为准。独立的云端账号及在线服务适用[云服务隐私政策](https://tano.page/zh-cn/privacy/)。

本地文件使用无需账号。Markdown、附件和 `.tano/` 元数据保存在所选工作区；索引、恢复草稿、助手历史、设置等设备状态保存在应用数据中，即使没有云服务也可能包含私人内容。原生凭据按对应功能使用操作系统凭据存储或进程内存，不作为可移植工作区数据。参见[应用数据](../local-development.md)、[账号导入](../account-import.md)、[助手](assistant.md)及[计划同步](planning-sync.md)。

Local 不包含私有 Cloud Overlay，也不自动把工作区上传 Tano 云端，但不是网络隔离软件。

## 联网行为与选择

| 触发方式 | 接收方及数据 |
| --- | --- |
| 启动及手动检查版本 | 请求 `https://tano.page/releases/local.json` 获取公告，不附加文档正文、工作区路径、账号凭据或设备标识。服务器及网络服务方仍能看到 IP、时间、HTTP 客户端请求头等元数据。当前启动时会查询，没有独立关闭公告请求的开关；查询不自动下载安装。 |
| 下载、源码和发布链接 | 浏览器访问所选网站，包括 GitHub、tano.page；对方收到普通请求数据，按其政策处理 Cookie 等信息。 |
| 文档远程图片、嵌入等资源 | 渲染可能直接请求文档 URL 指定的主机，不逐张图片另行确认。主机可看到请求元数据及 URL 中的信息。离线工作请使用本地附件并避免含远程资源的文档。 |
| 模型/API 和 CLI Agent | 配置并使用后，提示词、所选上下文、工具结果及请求的文件可能发送至供应商或 Agent。本机 CLI 可能连接云模型，本机进程不等于本地推理。 |
| MCP 和桌面 Agent Gateway | 启动 MCP 或启用 Gateway 后，Agent 获得授权数据，其后续传输受自身配置及政策约束；本机 IPC 或回环地址不保证 Agent 不外传收到的数据。 |
| 第三方账号导入 | 认证及内容选择请求直接发往所选平台，确认导入时保存到本地，不等于上传 Tano 云端。 |
| 可选 Git 同步 | 启用后，已提交的工作区文件、附件及 `.tano/` 元数据可能推送到所选远端；应用打开时可以自动重复同步。启用前核对远端权限和 `.gitignore` 排除项；关闭同步可停止后续自动传输，认证使用系统 Git/SSH 配置。 |
| 日历和 Todo 连接 | 根据授权交换所选事项及操作所需凭据；启用自动同步后，应用打开时可以继续请求。关闭连接的自动同步或断开连接可停止后续同步；启用前核对方向与上传范围。 |
| 插件及目录 | 浏览、下载配置的目录会联系运营方。获网络、原生或连接权限的插件可访问获准目标并处理权限内数据。请审阅源码、权限及政策，按需禁用或撤销授权。 |

离线工作时不启用可选连接并避免远程文档资源。可通过操作系统防火墙阻止启动公告等网络请求，相应功能将不可用。未创建云账号不表示所有联网能力关闭。

## 第三方规则

[英文政策表](../local-privacy.md#third-party-policies)提供 GitHub、Cloudflare、Google、Microsoft、Apple、飞书、Todoist、Notion、Atlassian（Confluence/Jira/Trello）、Evernote、Asana、monday.com、Quip、Workflowy、Roam、可选 OpenAI/Codex 和 Anthropic/Claude 的隐私入口。列出支持不表示默认连接或包含其私有客户端。

自定义模型、CalDAV、Git 远端、插件、Agent 及文档主机适用各自运营方政策。Windows、浏览器、系统 WebView2 和已安装 CLI 也有独立设置和数据处理。

## 保留、删除和联系

工作区文件和备份由你管理。断开连接并撤销第三方令牌可终止后续访问。清理应用数据可能删除设置、缓存、恢复及会话记录，请先导出需要的内容。卸载不等于删除工作区、备份、全部应用数据或第三方副本；外部数据删除应向对应运营方申请。项目不集中持有本地工作区，也不能远程删除它。

自愿发送的支持邮件和文件用于处理请求，邮件传输适用 Google 政策。请联系 [dramwig@gmail.com](mailto:dramwig@gmail.com)咨询或申请处理曾发送给维护者的材料，不要提供密码、API 密钥或无关私人文档。实质变更会更新政策日期并随受影响版本说明。
