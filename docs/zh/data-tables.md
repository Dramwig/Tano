# 数据表

[文档目录](README.md) · [架构](architecture.md)

数据表用于候选收集、横向比较和持续更新。每行是表内记录，不会自动生成 Markdown 文档。
数据表是普通的 `名称.table.json` 文件，与 Markdown 文档一起显示在仓库文件树中，可以放在任意目录。
右键目录或文件树空白处选择「新建数据表」，也可从打开文件面板或命令中心创建。命令中心的「新建配件选择表」提供配件模板。
点击文件直接打开表格；支持重命名、拖动到其他目录、标签页和移入回收站（浏览器演示中为删除）。修改表格标题会重命名文件，文件名是显示名称的依据。

## 编辑与比较

- 字段支持文本、数字、日期、勾选、单选、多选、链接、附件和公式。点击列标题就地打开属性菜单，可改名、更改类型、筛选、排序、分组、计算、隐藏、逐列换行、在左右插入和复制字段。
- 单选和多选的「编辑属性」提供选项列表，可添加、上下移动、重命名和设置颜色。重命名同步更新记录及精确匹配筛选；公式中的选项文字需要另行修改。配件模板预置分类和状态颜色。
- 直接编辑单元格，Enter 移到下一行；最后一行按 Enter 新建记录。Shift+Enter 在文本内换行。
- 从电子表格复制多行多列后，在目标单元格粘贴。按照当前可见记录和字段定位；超出末尾会新增记录。无效的数字、日期等会拒绝整批粘贴，避免只写入一部分。
- 勾选记录后可复制或删除。展开记录可查看完整文本和关联附件，删除记录不会删除原附件。
- 拖动列边界调整宽度，也可以聚焦调整柄后按左右方向键。视图设置提供自动换行、冻结第一列、字段显隐、筛选、排序和分组。
- 一个数据表可保存多个表格、卡片或看板视图。看板按分组字段组织，修改记录中的该字段即可换组。
- 底部汇总当前筛选结果，支持记录数、非空数以及数字的求和、平均、最小和最大值。
- 表头右上角菜单可以导入 CSV、导出当前视图或在同一目录另存副本。归档时直接把文件移到自己的归档目录，无需单独的数据表管理页面。

字段有数据时禁止直接改成另一种类型；移除仍在使用的选项也会被阻止。可新建目标字段再迁移数据，避免隐式转换丢失原值。

## 配件选择与公式

配件模板包括名称、类型、参数、价格、状态、计入金额和商品链接；不预置未经核实的商品或价格。
「最终配置」视图只显示状态为「选择」的记录。计入金额公式为：

```text
IF([状态] = "选择", [价格], 0)
```

公式支持 `+ - * /`、括号、比较运算、`IF`、`ROUND`、`ABS`、`MIN`、`MAX`、`SUM`、`AND`、`OR`、`NOT`。
字段引用在保存时转换为稳定字段 ID，改名不会破坏公式。空数字作为零参与算术；非数字文本不会隐式转成数字。
公式采用独立解释器，不运行 JavaScript、不访问网络或本机资源。循环引用、字段缺失和除零会显示错误；包含错误的列汇总明确显示错误。

## CSV

CSV 首行是字段名称。导入按同名字段的类型读取，新列默认为文本；导入追加记录，不覆盖已有记录。选择类字段会补充导入的新选项。
公式列导出计算结果，导入已有公式列时重新计算。CSV 不携带视图、字段 ID、公式定义和工作区附件本体；完整迁移请备份工作区与 `.tano/`。

## 存储与恢复

表结构、字段、记录及共享视图完整保存在用户选择目录的 `.table.json` 文件内。它是用户内容文件；`.tano/` 仍用于平台元数据和恢复副本。文档正文仍由 Markdown 承载，主数据不放进 SQLite、浏览器会话或二进制协作状态。
表格标签页按工作区文件 ID 定位，不依赖路径；重命名和移动不会改变文件身份。文件里的表、行、字段和视图保留各自 ID。直接在文件管理器复制整个文件后，两份文件仍独立打开和保存，不会因为内部表 ID 相同而合并。

旧版 `.tano/tables/<tableId>.tano.json` 在可写工作区打开时迁移到仓库根目录，同名时自动加序号，并在 `.tano/conflicts/table-migration-*` 保留原始字节。原有记录、视图和已归档表都保留；损坏、只读或迁移失败的原文件不会被删除或重置。

保存使用基线 hash。独立字段、单元格和记录修改可以合并；重叠修改保留外部文件，并把完整本地版本保存到 `.tano/conflicts/`，暂停编辑，提供重试、另存副本和保留恢复文件后重新载入。
未保存草稿和基线进入应用会话恢复记录，不写到工作区根目录。损坏或未来版本的表文件不会被重置。

浏览器演示仅保存在当前浏览器，表写入要求 Web Locks；它不等同于网络协作。桌面端复用现有原子文件写入及路径限制。
附件引用使用现有工作区文件 ID；浏览器演示使用内置附件。当前本地 MCP 文档工具不读写数据表，也不声明数据表实时网络协作能力。

单表上限为 8 MiB、200 个字段、50000 条记录和 100 个视图；单次粘贴最多 10000 行。当前公式按行计算，不支持跨表查询、Excel 单元格坐标或复杂自动化。
