# Documentación de Tano

[English](../README.md) | [简体中文](../zh/README.md) | [繁體中文](../zh-tw/README.md) | [日本語](../ja/README.md) | Español | [Deutsch](../de/README.md) | [README del proyecto](../project-readme/README_ES.md)

Tano es un espacio de trabajo en el que personas y agentes colaboran sobre archivos reales, que siguen siendo la fuente de verdad del contenido. Consulta [Desarrollo local](local-development.md) para iniciar la aplicación de escritorio o la demo en el navegador. Las guías de uso están en la [documentación oficial en español](https://tano.page/es-es/docs/).
