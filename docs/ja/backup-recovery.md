# バックアップと復旧

[English](../backup-recovery.md) | [中文](../zh/backup-recovery.md) | 日本語 | [Deutsch](../de/backup-recovery.md) | [ドキュメント一覧](README.md)

Markdown ファイル、添付ファイル、`.tano/` ディレクトリ全体を一緒にバックアップしてください。ワークスペースの UUID、ファイルの ID、オブジェクト、関係、ルールは持ち運べる元データであり、削除してよいキャッシュではありません。

Tano はワークスペースの自動バックアップ、アーカイブのインポート・エクスポート、復元を提供しません。Tano の外でワークスペースのフォルダーを削除した場合、開く操作は失敗し、フォルダーや内容は再作成されません。復旧には、ご自身のバックアップツール、バージョン管理、または OS のごみ箱を使用してください。

ワークスペースのフォルダーが残っていて、`.tano/` 全体が削除された場合、開き直すと新しいワークスペースとして初期化し、新しい UUID とファイル ID を割り当てます。元のメタデータと旧オブジェクトのデータが失われ、プロジェクトを再初期化したことを通知します。既存の Markdown と添付ファイルは変更せず、`.tano/` とともに削除されたオブジェクト、関係、ルールは復元しません。旧ワークスペースの索引、下書き、セッションも再利用しません。ID 情報の一部だけが欠けている場合、破損している場合、ID が一致しない場合は引き続き開く操作を停止します。開いているセッションでは、開き直して初期化するまで書き込みを停止します。

下書きのジャーナルはアプリデータに保存され、アプリ再起動前の未保存の編集を保持しますが、ワークスペースのバックアップではありません。外部変更には引き続き基準ハッシュの比較、三方向マージ、競合内容の保存が適用されます。
