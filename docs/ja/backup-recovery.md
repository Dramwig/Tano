# バックアップと復旧

[English](../backup-recovery.md) | [中文](../zh/backup-recovery.md) | 日本語 | [Deutsch](../de/backup-recovery.md) | [ドキュメント一覧](README.md)

Markdown ファイル、添付ファイル、`.tano/` ディレクトリ全体を一緒にバックアップしてください。ワークスペースの UUID、ファイルの ID、オブジェクト、関係、ルールは持ち運べる元データであり、削除してよいキャッシュではありません。

ネイティブコアはアプリデータにメタデータのスナップショットを保存します。既知のワークスペースで ID 情報が失われた場合、通常のオープンと書き込みは停止します。新しい UUID を割り当てず、復旧画面で内容を確認してから復元してください。完全なエクスポートには文書の内容とアプリデータが含まれます。インポート時にはバイト単位のダイジェストを検証し、既存の保存先は上書きしません。

下書きのジャーナルもアプリデータに保存されます。外部変更には引き続き基準ハッシュの比較、三方向マージ、競合内容の保存が適用されます。復旧に失敗してもデータと記録は残ります。ローカルのスナップショットとは別に、ほかの機器や媒体にもバックアップを保管してください。
