# 界面语言

桌面工作台支持简体中文和 English，默认使用简体中文。在「设置 → 外观设置 → 界面语言」切换后即时生效，独立设置窗口与主窗口同步。

语言偏好保存在应用 WebView 的 `localStorage`（`tano.preference.locale`），属于当前设备的应用状态，不写入工作区。切换语言不翻译文档正文、文件名、工作区名称、用户模板或插件提供的内容。

## 开发约定

- 页面文案通过 `packages/workbench/src/i18n.ts` 的 `t()` 获取，以中文原文作为键，英文写入 `locales/en-US.ts`。
- 动态值使用 `{0}`、`{1}` 等占位符，并通过第二个数组参数传入。不要将用户内容作为翻译键。
- 需要即时切换的数组标签使用 `computed` 或 getter，避免在组件初始化时固定语言。
- 协议类型、存储字段和标识符保持原值，只在展示边界翻译标签。
- 图标英文标签通过 `node scripts/build-ui-icon-labels.mjs` 生成，使用 `--check` 检查一致性。

运行 `npm run check` 验证类型、消息覆盖、占位符、组件和构建；运行 `npx playwright test locale-browser.spec.mjs` 验证页面切换、语言保存与文档内容保护。

本阶段覆盖工作台页面和设置。编辑器内部菜单、原生系统对话框和底层服务错误文案仍可独立扩展。

## AI 提示词与输出语言

AI 的内置任务提示词、评论回复指令、来源数据说明和语言策略统一使用英文，集中维护在 `packages/workbench/src/assistant/task-prompts.json`。界面按钮、生成进度、工具展示名称及浏览器模拟响应使用 `assistant/locales/zh-CN.json` 和 `en-US.json`。系统的工具契约、权限约束和文件操作规则保留一份，通过 `assistantSystemMessages()` 组合当前任务的语言策略，不需要复制两套执行逻辑。

- 普通回答、总结、澄清问题及选项、操作原因的语言优先级为：用户明确指定的语言 → 用户当前自由输入的语言 → 发起任务时的界面语言。判断输入语言时排除引文、文档、历史、代码和工具说明；混合输入以请求主体语言为准，无法判断时使用界面语言。
- 语言策略本身也用英文描述，例如 `The fallback response language for this task is Simplified Chinese (UI locale: zh-CN).`。中文界面的快捷按钮保持中文，点击后填入统一的英文任务提示词。快捷任务、开始草稿和评论回复入口通过 `setBuiltInPrompt()` 标记来源，英文模板不算用户自由输入，因此默认回复界面语言。用户编辑模板后按自由输入处理；手动输入的请求按原文发送。
- 模式提示词也统一使用英文，位于 `task-prompts.json` 的 `modes.inline` 和 `modes.sidebar`。每次请求只添加当前模式：行内模式处理一次任务、简短回复，缺少信息时说明需要补充什么并引导进入侧栏；侧栏模式支持多轮对话和逐项审阅，仅在实际提供 `ask_user` 时要求调用提问表单，否则用普通文本提问。两种模式共用输出语言策略。
- 润色、纠错、续写和局部编辑保留原文语言；混合语言内容保留各部分的语言。翻译使用明确的目标语言，界面分别提供「翻译成英文」和「翻译成中文」。
- 发起任务时固定语言，覆盖参考内容加载、工具调用、等待用户回答和后续轮次。任务中切换界面语言只影响下一次发起的任务。
- 用户输入、文档内容、历史会话和工作区规则按原文传递。评论引用和讨论内容作为 JSON 数据附加，不进行自动翻译。
- 工具名称、JSON 字段、枚举值、文件路径、对象 ID 和 `[来源:S1]` 引用标记保持协议规定的值。传输层继续接收标准消息和工具，无需新增后端协议字段。
- 原生 CLI 包装指令遵循同一优先级，区分用户输入和内置模板。真实 API 语言验收可运行 `scripts/assistant-locale-live.mjs`：设置外部证据目录 `TANO_LOCALE_EVAL_OUTPUT`，先用 `--list` 查看可用模型，再设置 `TANO_LOCALE_EVAL_MODEL` 执行；它使用已配置连接及服务额度，仅发送合成文档，不写入文档或会话。输出保留请求和回复，供逐项核对语言及模式行为。

`assistant/language.test.ts` 检查两个 JSON 的键与占位符一致性；提示词、会话、面板及模拟传输测试覆盖语言切换和内容保护。这些检查验证请求与界面行为，真实模型是否遵循输出语言仍取决于所选模型的指令遵循能力。
