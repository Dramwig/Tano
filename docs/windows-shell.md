# Windows 右键打开

Windows 安装程序提供两个独立的可选项，首次安装默认不勾选：

- **文件夹**：在文件夹本身及文件夹空白处的右键菜单加入“通过 Tano 打开”，将该目录作为工作区。
- **Markdown 文件**：在 `.md` 和 `.markdown` 文件的右键菜单加入“通过 Tano 打开”，进入独立文件编辑窗口。

这些菜单注册在当前用户下，不需要管理员权限，不修改默认文件关联。
Windows 11 目前在 **显示更多选项** 中显示这些菜单；尚未实现截图中新版菜单
所需的 `IExplorerCommand` 扩展及带包身份的签名部署。
参见 [Microsoft 的新版菜单接入要求](https://learn.microsoft.com/en-us/windows/apps/desktop/modernize/integrate-packaged-app-with-file-explorer)。

重新运行安装程序可以更改选项。更新安装保留已有选择，卸载移除 Tano 自己的菜单。
静默安装可显式指定 `/TANOFOLDERS=1` 和 `/TANOMARKDOWN=1`，值为 `0` 时移除相应菜单；
未指定时沿用已有选择，首次静默安装不会自动注册菜单。

## 打开与保存行为

安装程序调用以下入口；可执行文件和路径必须分别加双引号：

```text
"C:\...\tano.exe" --open-folder "D:\笔记 工作区"
"C:\...\tano.exe" --open-file "D:\笔记 工作区\文章.md"
```

已运行的 Tano 接收后续打开请求。同一文件复用已有独立窗口，文件夹请求交给
主工作区窗口，沿用工作区切换前的保存检查。

独立文件窗口直接读写所选文件，不扫描父目录，不创建 `.tano` 工作区数据。
支持编辑、源码模式、Ctrl+S、另存副本和关闭前的未保存提示；本地草稿保存在
应用数据中。聚焦窗口时检查磁盘变化，保存时比较基准哈希，合并互不重叠的修改。
冲突时保留本地编辑和磁盘内容，不覆盖原文件，可另存副本。
另存副本不覆盖已存在的目标文件。单文件窗口不提供工作区对象、附件导入和关系管理。

## 本地验证

运行 `npm run check`、`npm run test:native` 和 `npm run desktop:build`。
安装验收应覆盖两个选项分别启用/禁用、升级保留选择、卸载清理，以及中文和空格路径。
分别验证冷启动和已有实例中的文件夹、Markdown 文件打开，并确认保存冲突时原文件不变。
