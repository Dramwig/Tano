## Folder homes

Open the [sample project](sample-project/README.md), then click its folder in the file tree to check that it opens the same home document. The default filename is `README.md`; workspace general settings can use `_index.md`, `index.md`, or disable folder homes.

- [ ] Expand the folder, open its [review checklist](sample-project/review-checklist.md), and return through the breadcrumb.
- [ ] Convert a practice document into a folder with a home, then create a child document.
- [ ] Convert back when allowed. Other child files must be handled first and must not be silently deleted.
- [ ] Check file identity, open tabs, and relative image links before and after conversion.

Use a new practice document for conversion so the sample navigation paths remain available.

## Tabs and layout

- [ ] Open two documents and drag tabs to reorder them. Cancelling a drag should restore the layout.
- [ ] Try split panes, duplicate tabs, and separate windows where supported on desktop.
- [ ] Switch between Home, folders, and documents, then return to the open documents.

## Attachment reading and spreadsheets

The [image](assets/test-image.png) and [text attachment](assets/sample%20attachment.txt) support demo preview or download. The following exercises need a desktop workspace and your own attachment copies; Office binaries are not bundled here.

| File | What to check |
| --- | --- |
| PDF | Continuous reading, thumbnails, page navigation, zoom, and fit width |
| DOC/DOCX | Default Word preview plugin, source paper dimensions, continuous pages |
| PPT/PPTX | Default presentation plugin, slide navigation, and zoom |
| XLS/XLSX | Worksheet navigation, cell copying, widths; editing and save status in writable local files |

Word and presentation previews are read-only. Legacy DOC, complex layouts, missing fonts, and animations may differ from Office. Excel supports limited text editing and does not calculate new formulas. Structural operations may be blocked for workbooks with formulas, defined names, or macros. Web and other hosts without a writer remain read-only. Practice on attachment copies and inspect save or conflict notices.
