# 文件导航与附件

[English](../en-US/12-files-and-attachments.md) · [导航](00-从这里开始.md)

## 文件夹首页

打开[示例项目](示例项目/README.md)，再从文件树点击该文件夹，检查是否打开同一篇首页。默认首页名称为 `README.md`，可在工作区常规设置中切换为 `_index.md`、`index.md` 或关闭。

- [ ] 展开文件夹，打开[验收清单](示例项目/验收清单.md)，通过面包屑回到项目首页。
- [ ] 把练习文档转换为带首页的文件夹，再创建一篇子文档。
- [ ] 在允许转换时转回普通文档；有其他子文件时应先处理它们，不能静默删除。
- [ ] 转换前后检查文件身份、已打开标签页和相对图片链接。

使用新建的练习文档进行转换，以便保留这套示例的导航路径。

## 标签页和布局

- [ ] 同时打开两篇文档，拖动标签调整顺序；取消拖动应恢复布局。
- [ ] 尝试分屏、复制标签页以及桌面端支持的独立窗口。
- [ ] 在主页、文件夹与文档间切换，检查已打开文档仍可返回。

## 附件阅读与电子表格

[图片](assets/测试图片.png)和[文本附件](assets/示例%20附件.txt)可在演示中预览或下载。以下练习需要桌面工作区和自行准备的附件副本，示例不包含 Office 二进制文件。

| 文件 | 检查内容 |
| --- | --- |
| PDF | 连续阅读、缩略图、页码、缩放与适合宽度 |
| DOC/DOCX | 默认 Word 预览插件、原始纸张尺寸、连续页面 |
| PPT/PPTX | 默认演示文稿插件、幻灯片切换与缩放 |
| XLS/XLSX | 工作表切换、单元格复制、列宽；可写本地文件的单元格编辑与保存状态 |

Word 和演示文稿是只读预览。旧 DOC、复杂排版、缺失字体、动画等可能与 Office 不同。Excel 编辑是有限的文字编辑，不计算新公式；带公式、命名区域、宏等文件的结构操作可能被阻止。网页与不支持写入的宿主保持只读。请在附件副本上练习，并检查保存或冲突提示。
