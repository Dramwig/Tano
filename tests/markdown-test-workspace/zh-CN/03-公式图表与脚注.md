# 公式、Mermaid 与脚注

[English](../en-US/03-math-diagrams-and-footnotes.md) · [导航](00-从这里开始.md)

美元行内公式：$a^2+b^2=c^2$；LaTeX 行内公式：\(a^2+b^2=c^2\)。

美元公式块：

$$
E = mc^2
$$

LaTeX 公式块：

\[
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
\]

行内代码 `$x$` 和下面代码块中的公式应保持源码文本：

```latex
\[x^2 + y^2 = z^2\]
```
