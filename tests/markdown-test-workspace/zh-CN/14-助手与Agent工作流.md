# 助手与 Agent 工作流

[English](../en-US/14-assistant-and-agents.md) · [导航](00-从这里开始.md)

以下任务是练习素材，不会因为打开本页而运行。浏览器演示使用模拟响应；真实调用需要桌面模型连接，或官方产品中已登录账号可用的服务端模型。模型是否开放以当前连接列表为准。

## 会议素材

今天确认了编辑器和文件导航的验收范围。先核对既有任务，再决定是否新建行动项。公式复制还需要在目标编辑器验证；没有验证结果时不要标记完成。

- [ ] 检查多块源码编辑的撤销。
- [ ] 核对文件夹首页中的相对链接。
- [ ] 汇总附件预览限制。

## 问答、建议与执行

1. 选中上面的会议素材，打开行内助手，请它总结三条结论并标明未验证项；需要时继续到侧栏对话。
2. 请求「先给建议，不要修改：改写这一段，保留任务状态」，检查差异后决定采纳或逐项审阅。
3. 在练习文档中明确请求「把第一句改为……并保存」，检查文件变更清单和实际保存结果。明确执行指令可以直接写入，不会一律等待第二次确认。
4. 让助手搜索本工作区相关文档或数据表并给出处。参考用于指定重点，不是默认的访问范围隔离；选区仍限定本次局部改写。

API、Codex CLI 和 Claude CLI 在桌面「模型连接」中配置。可以查看连接状态、会话 Token 用量和可用的服务商额度查询；用量统计不等于账户余额。密钥和会话保存在工作区外。

## 用 @ 派发给 Agent

在支持的工作区配置连接后，检查「机器人收件箱」的模型和自动处理设置。在正文、批注或评论里输入 `@`，从选择器选中实际 Agent，再写清任务并保存或发布。

- [ ] 观察排队、执行、等待回复和完成状态，打开执行记录检查工具回执。
- [ ] 需要澄清时在对应讨论中回复；取消任务不会撤销已保存的修改。
- [ ] 本地执行需要应用运行；云端托管执行需要服务已配置并可用，不代表本机 CLI 会在关闭应用后继续运行。

手写普通对象引用、复制本页文字或在代码中写 `@Agent` 不会自动派发。示例人物不是已连接的机器人。

## 外部 MCP

从桌面 MCP 面板复制配置。默认 `review` 允许读取和提交待审提案；`read` 只读；显式 `write` 才启用旧 Markdown 直接写入工具。Gateway 可以查询文件、对象、关系和数据表，批量提案仍在 Tano 中审阅。

提交成功不代表已写入；检查每项回执。结果待核对或发生冲突时，先核对实际内容，不重复执行旧请求。
